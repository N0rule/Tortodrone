- Tortodrone is a server-side Spiral Knights server emulator written in Java. Do not develop or modify the game client.
- Do not support Steam authentication or guest login; use normal username/password accounts.
- Commit every major completed change with a clear commit message, and increment the version number in `VERSION` if it makes sense.
- After changes, rebuild and test; starting a server for testing is allowed. Leave it stopped when finished so I can start it myself.
