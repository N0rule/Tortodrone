# Historical research

These documents record past protocol observations, source references, and
experiments. Names such as `TortodroneServer`, old build paths, namespace commands,
client probes, client repairs, and temporary client patches reflect those earlier
experiments. They are not current setup or implementation instructions.

Current work is strictly on the Tortodrone server, with normal username/password
login only. Do not use these records as authorization to change clients, launchers,
game archives, controls, or client home-directory state, or to add Steam/guest
login. See [AGENTS.md](../../AGENTS.md) for the project's rules.

Use the [README](../../README.md), [development guide](../development.md),
[server architecture](../server-architecture.md), and
[connection guide](../client-redirection.md) for current behavior.
