# Future plugins

This directory is reserved for a future Java plugin API inspired by PaperMC.
No plugin loading or executable scripts are implemented. Ordinary content editing
uses config/ and content/ and requires only a server restart.

A future API may expose supported gameplay events, commands and controlled engine
hooks. Plugins must preserve authenticated ownership, scene authority, transaction
boundaries and the unchanged client protocol. This placeholder makes no compatibility
promise about a future API and does not enable unsupported assets or game behavior.
